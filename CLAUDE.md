# Supercharged

A collection of open source forks with custom features. See `README.md` for project overview.

## Key Files

- `repos.json` -- Registry of all forked projects (name, repo URLs, local paths)
- `playbook.md` -- Step-by-step guide for setting up a new supercharged fork
- `project-disclaimer.md` -- Template disclaimer for fork READMEs

## Scripts

- `list-peacock-colors.sh [search-dir]` -- List all VS Code Peacock colors in use across projects. Defaults to `~/projects`. Run before assigning a color to a new project to avoid collisions.
